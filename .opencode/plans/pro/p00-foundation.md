# P0 — Monorepo, licence, protocol contract

## Outcome

The `lumen-pro` branch holds the following:

- **Licence:** the proprietary licence.
- **Folders:** the four product folders.
- **Protocol:** a machine-checkable protocol contract with fixtures.
- **CI:** CI that runs every product's checks.
