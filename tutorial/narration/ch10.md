# ch10

When one controller is not enough, Lumen controllers can work together.

They talk to each other over ESP-NOW, a radio protocol built into the ESP32. No router, no MQTT broker and no internet connection are needed between them.

To link controllers, give them the same network ID and the same network key. The key is generated the first time you enable the feature, and you copy it from one controller to the others.

Every frame between controllers is signed with that key using HMAC SHA-256, and frames that are replayed, stale or tampered with are dropped.

There is one practical requirement: all controllers must be on the same Wi-Fi channel, which in practice means connected to the same access point.

In this demo, the KC868-AP is linked with a generic ESP32 DevKit, which drives two lights from its own PWM pins.

On the Devices page, the Controllers tab shows every peer, its address, firmware version, signal strength and whether it is online, together with its lights.

You can switch the lights of another controller from here. The command travels over ESP-NOW to the controller that owns the light, and that controller applies it to its own hardware.

The state comes back the same way, so the other controller's own web app shows the change at once.

Scenes can also span controllers. Activating a network scene runs the scene with the same ID on every controller that has one.

A network can have up to eight peers, and each controller keeps working on its own if the others are offline.
