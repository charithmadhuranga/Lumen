The last stop is the Settings page, where you look after the controller over time.

Appearance offers a light theme, a dark theme, or following your system. The app also respects reduced motion if your device asks for it.

Backup downloads a single file with your lights, rooms, groups, scenes, automations, hardware and integration settings. Passwords and keys are never included.

Restoring is transactional. The backup is validated first, and if anything is wrong, nothing changes. You can replace everything, or merge only the parts the file contains.

Firmware updates use the two firmware slots. A new image is checked before anything is written, and verified in full before it is selected.

After the restart, the new firmware has to prove that it is healthy. If it does not start correctly, the controller automatically returns to the previous version. Your settings are kept either way.

The web app is updated separately with its own package. If an update is ever interrupted, a small recovery page built into the firmware lets you install it again.

At the bottom, the System card shows the firmware version, the chip, the active board profile, the running slot, storage, memory and uptime, with buttons to restart or to factory reset.

A factory reset erases configuration and credentials, so it always asks for confirmation.
